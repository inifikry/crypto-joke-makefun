# Crypto Joke

Entry for "Laugh Track: The Crypto Trading Joke Contest" on make.fun.

`main.py` writes a single one-line joke about crypto trading life to
`/output/entry.txt`. The line is fixed and deterministic, so every run
produces the exact same output.

Run it with:

```sh
python3 main.py
```

The joke: "I bought the dip, then the dip dipped. Now I own the entire
dip family — and they're all red."
